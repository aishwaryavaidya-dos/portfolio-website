# Aishwarya Portfolio

A responsive React portfolio inspired by the supplied reference screenshot.

## Run locally
```bash
npm install
npm run dev
```

## Add your profile photo
Put your photo in `public/profile.jpg`. The circular portrait automatically uses it. If the file is missing, a stylized placeholder with the letter A appears.

## Customize before publishing
- Update links in `src/App.jsx` (GitHub, LinkedIn, email, resume, paper and project URLs).
- Put your resume PDF at `public/resume.pdf`.
- Replace project descriptions, experience dates, skills and research details with your final content.
- Deploy the folder to Vercel, Netlify, or another static hosting service.
